### 🔬 Currently

**[lowbit-atlas](https://github.com/matheus-c-feitosa/lowbit-atlas)**: an independent check of low-bit (1-bit, ternary, 2-bit) LLMs on CPU. For each model file, runtime and CPU, two questions: does the output match a reference, and how fast is it?

- Microsoft's bitnet.cpp main still gives wrong output on CPU (~6× the reference perplexity on x86, garbage on ARM); I measured which of the proposed fixes actually work against the Hugging Face reference.
- Speed depends on file × runtime × CPU: up to 34× for the same model on x86.
- Every number comes with the runtime commit, the file sha256 and a script to rerun it.
